# Portafolio — Andrés Cagua

Portafolio personal de una página, construido con **Astro 5** (output estático), TypeScript y CSS moderno sin frameworks.

## Comandos

```bash
npm install      # instalar dependencias
npm run dev      # servidor de desarrollo en localhost:4321
npm run build    # build de producción en dist/
npm run preview  # previsualizar el build
```

## Deploy

Listo para Netlify (o cualquier hosting estático): el build genera archivos estáticos en `dist/`. Build command: `npm run build`, publish directory: `dist`.
